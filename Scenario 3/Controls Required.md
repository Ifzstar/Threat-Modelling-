**Controls Required:**
- AI-Powered Traffic Monitoring: Deploy advanced AI/ML-based network traffic monitoring systems to identify and mitigate anomalous patterns of traffic indicative of DDoS attacks.

- Rate Limiting: Enforce strict rate-limiting policies to restrict the number of requests that can be sent from a single IP address or user in a short period.

- Web Application Firewall (WAF): Implement a WAF to detect and filter malicious DDoS traffic while allowing legitimate requests to pass through.

- IP Reputation and Blacklisting: Use IP reputation services to block known malicious IP addresses and continuously monitor for new threat actors.

- Geo-Fencing: Restrict traffic from geographical regions that are not part of ShopNow's core user base to reduce the attack surface.

- CAPTCHA Challenges: Implement CAPTCHA and other human-verification tools for critical requests to distinguish between bots and legitimate users.

- Load Balancing: Use load balancing across multiple servers or cloud providers to distribute traffic, preventing a single point of failure during an attack.

- Content Delivery Network (CDN): Utilize a CDN to absorb and filter excessive traffic, reducing the direct load on ShopNow's servers.

- Behavioral Traffic Analysis: Implement behavioral analytics to detect and respond to anomalies in traffic flow, such as sudden surges or bot-like behavior.

- Backup and Failover Systems: Establish failover systems and backup servers to maintain operational continuity in the event of a prolonged DDoS attack.

- Third-Party DDoS Mitigation Services: Partner with specialized DDoS protection vendors to leverage advanced mitigation tools and expertise during an attack.
